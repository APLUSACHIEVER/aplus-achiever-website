One-time setup

  1. Replace the URL and anon/publishable key in config/supabase-config.js.
  2. Run database/supabase.sql in Supabase SQL Editor.
  3. Create your owner account through Student Login.
  4. In Supabase, change that account's profiles.role from student to admin.

Never put a service_role/secret key in GitHub Pages.
